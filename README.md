# Introducción a la Ciencia de Datos

Este repositorio reúne el material de estudio, código, prácticas y proyectos correspondientes al curso de Introducción a la Ciencia de Datos. Su objetivo principal es estructurar y documentar con claridad el flujo de aprendizaje y aplicación práctica de las técnicas de análisis, procesamiento y modelado de datos utilizando Python.

---

## Enfoque y Contenido

El repositorio abarca las etapas centrales del flujo de trabajo en ciencia de datos:
* Procesamiento y Limpieza de Datos: Manejo de datos estructurados, imputación de valores faltantes y transformación.
* Análisis Exploratorio (EDA) y Visualización: Extracción de patrones, identificación de correlaciones y generación de gráficos estadísticos.
* Modelado y Estadística Aplicada: Aplicación de principios estadísticos y algoritmos de Machine Learning supervisado.

---

## Organización del Repositorio

La estructura del proyecto queda organizada en los siguientes directorios:

* [book/](./book/): Notas de lectura, síntesis teóricas y referencias bibliográficas basadas en literatura de apoyo.
* [classes/](./classes/): Notebooks y material desarrollado durante las sesiones de clase, incluyendo explicaciones teóricas y código guiado.
* [practices/](./practices/): Prácticas de laboratorio, retos y ejercicios aplicados a conjuntos de datos reales.
* [project/](./project/): Proyectos del curso:
  * `Notebook Preprocesamiento`: Limpieza, imputación y análisis del conjunto Breast Cancer Wisconsin.
  * `Notebook de regresión`: Modelado con regresión lineal simple y múltiple sobre calidad de vinos.
  * `notebook metricas de clasificacion`: Evaluación con matriz de confusión, curvas ROC y curvas PR sobre Bank Marketing.

---

## Tecnologías Utilizadas

* Lenguaje: Python 3.x
* Entornos: Jupyter Notebook / JupyterLab
* Librerías principales:
  * Manipulación de Datos: NumPy, Pandas
  * Visualización: Matplotlib, Seaborn
  * Modelado y Machine Learning: Scikit-Learn, SciPy
