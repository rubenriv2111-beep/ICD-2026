# Practica 1 - Analisis Exploratorio y Visualizacion de Calidad del Agua

## Descripcion del Dataset
El archivo de datos contiene registros de la Red Nacional de Medicion de Calidad del Agua (RENAMECA), administrada por la Comision Nacional del Agua (CONAGUA).
- Nombre del archivo - TODOS LOS MONITOREOS.xlsb
- Hoja principal - RESULTADOS
- Cobertura temporal - Mediciones del 2012 al 2025
- Contenido - 126,070 registros y 493 variables fisicoquimicas, microbiologicas y metales en cuencas de Mexico
- Unidad de observacion - Evento individual de monitoreo por sitio y fecha

## Requisitos de Ejecucion
- Python 3.10 o superior
- Jupyter Notebook o Visual Studio Code

Librerias requeridas
- pandas
- numpy
- matplotlib
- seaborn
- python-calamine o pyxlsb

Instalacion de dependencias
```bash
pip install pandas numpy matplotlib seaborn python-calamine
```

## Instrucciones de Uso
1. Descomprimir el archivo del dataset si se encuentra comprimido en formato zip.
2. Colocar el archivo TODOS LOS MONITOREOS.xlsb en la misma carpeta del notebook.
3. Abrir el archivo practica-1.ipynb en el entorno Jupyter.
4. Ejecutar las celdas de forma secuencial de inicio a fin.
5. Las salidas y tablas estadisticas se despliegan directamente en el documento.

Se entregara el enlace al repositorio y el notebook en la plataforma del curso.
